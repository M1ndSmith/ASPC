Master Pipeline Overview
End-to-end decisional flow from raw sensor data to SPC-ready output
ℹ
SPC cleaning ≠ ML cleaning. In ML you optimize prediction accuracy and can transform freely. In SPC, every step must preserve the physical meaning of variation. False signals caused by bad cleaning are as harmful as real defects going undetected.

⚠
The three cardinal rules of SPC data preparation: (1) Never silently remove data — every gap must be traced to a root cause. (2) Preserve temporal order — SPC is time-ordered analysis. (3) Validate the measurement system BEFORE cleaning process data.
02
Normality & Distribution Decision Tree
The most critical branching point — determines chart type, capability index, and transformation strategy
SPC assumes independence and approximate normality. Autocorrelation must be checked first — it invalidates standard control limits entirely. Non-normality, while important, is secondary and is handled through transformation or chart selection. Per Donald Wheeler and Irving Burr's research on 27 distributions, Shewhart 3σ charts remain robust for most non-normal data when zone tests are omitted.

05
MSA & Gage R&R Flow
Run before any data cleaning — a bad gage invalidates everything downstream
Total observed variation = σ²_process + σ²_measurement_system. If measurement system variation is large, SPC charts show ghosts — you adjust machines that run perfectly because the gage lied to you. The AIAG MSA-4 standard defines the acceptance criteria: %GRR < 10% acceptable, 10–30% conditional, > 30% unacceptable — stop.
FIG 5.1 MSA / GAGE R&R COMPLETE FLOW — STATIC AND REAL-TIME
flowchart TD A([Start: Data Pipeline\nInitialization]) --> B{Measurement\nSystem Type?} B -->|Manual / Periodic\nStatic Gage| C[STATIC MSA — AIAG MSA-4] B -->|Automated Inline\nContinuous Sensor| D[REAL-TIME CONTINUOUS MSA] subgraph STATIC ["STATIC GAGE R&R — CROSSED STUDY"] C --> C1[Select 10 representative parts\nspanning full process range] C1 --> C2[Assign 2-3 appraisers\nblind to each other] C2 --> C3[Each appraiser measures\neach part 2-3 times\nMin 60 measurements total] C3 --> C4[ANOVA decomposition\nσ²_repeatability + σ²_reproducibility + σ²_part] C4 --> C5[Compute %GRR\n= σ_GRR / σ_tolerance × 100] C5 --> C6[Compute NDC\nNumber of Distinct Categories] end subgraph REALTIME ["REAL-TIME CONTINUOUS MSA"] D --> D1[Insert certified\nreference standards\nat fixed intervals in stream] D1 --> D2[Record deviation from\nknown reference value] D2 --> D3[EWMA of bias\nα = 0.2] D3 --> D4[Rolling R chart\non repeat reference measurements] D4 --> D5{EWMA bias >\n±10% tolerance?} D5 -->|YES| D6[🔴 Trigger calibration alert\nSuspend measurements] D5 -->|NO| D7[✅ Gage healthy\nContinue monitoring] end C6 --> E{%GRR result?} E -->|< 10%| F[✅ ACCEPTABLE\nProceed to data cleaning] E -->|10 – 30%| G[⚠️ CONDITIONAL\nDocument risk level] E -->|> 30%| H[🔴 UNACCEPTABLE\nSTOP — fix gage first] E --> I{NDC ≥ 5?} I -->|NO| H I -->|YES| F G --> J{Cp of process\n> 2.0?} J -->|YES| F J -->|NO| H style F fill:#081a0d,stroke:#39FF6E,color:#39FF6E style H fill:#1a0808,stroke:#FF6B35,color:#FF6B35 style D6 fill:#1a0808,stroke:#FF6B35,color:#FF6B35 style D7 fill:#081a0d,stroke:#39FF6E,color:#39FF6E
NDC Rule
NDC = 1.41 × (σ_part / σ_GRR). Must be ≥ 5. NDC < 5 means the gage cannot discriminate between parts sufficiently for SPC analysis.
Resolution Rule
Gage resolution ≤ tolerance/10 (the "10:1 rule"). For ±0.1 mm tolerance (0.2 mm total), gage must resolve ≤ 0.02 mm.
Calibration Interval
Real-time EWMA drift detection enables predictive calibration — trigger on statistical drift, not just fixed calendar intervals.
06
Missing Value Classification & Handling
In SPC, a missing value is a quality event — not an unknown. The cause determines the treatment.
⚠
Cardinal rule: Never impute with mean/median for control chart data — it artificially reduces variation and narrows control limits. Never silently drop records. Every missing value must be classified and flagged with a data_quality_flag.

PHASE I GO-LIVE VALIDATION CHECKLIST
  • MSA %GRR < 10% of tolerance AND NDC ≥ 5 confirmed and documented
  • Normality test result documented; distribution path chosen and recorded
  • ACF/PACF checked — autocorrelation addressed if present
  • All outliers investigated — special causes removed with root-cause notes; common causes retained
  • Missing data: 100% classified with data_quality_flag; no silent imputation on control chart data
  • Minimum 25 subgroups (AIAG) used for limit computation
  • Control limits computed and FROZEN — stored in DB with version hash
  • Transformation documented, reversible, and applied consistently to future data
  • Gage calibration date confirmed within active calibration interval
  • Phase II monitoring mode enabled — limits locked, alerts configured
